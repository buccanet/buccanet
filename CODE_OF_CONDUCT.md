# Code of conduct

Buccanet adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every Buccanet space: issues, pull requests, discussions, reviews and Buccanet rooms used for the project, and when someone represents the project in public.

## Reporting

Report unacceptable behavior privately to the maintainers through GitHub: open a private report at https://github.com/buccanet/buccanet/security/advisories/new and start its title with "Conduct", or contact the maintainers of the `buccanet` organization on GitHub (https://github.com/buccanet). Every report is reviewed, and the maintainers keep the reporter's identity private.

The maintainers apply the enforcement guidelines of the Contributor Covenant 2.1: correction, warning, temporary ban and permanent ban.
